## 来源与维护

图标、手机、服务器、桥梁等视觉与器乐配乐、动作拟音为本项目制作。动画使用 [huashu-motion](https://github.com/alchaincyf/huashu-motion) 0.3.1 编写和渲染；画面字体使用 Inter 与 Noto Sans SC，应用图标使用项目 SVG 和 Lucide。第三方工具与字体保留各自许可证，未在此分发工具或字体文件。

完整分镜、可编辑 HTML/JavaScript、工具许可证、高清母版和历史版本在独立制作目录维护，不进入应用 Git 仓库。更新时仅替换本目录的最终成片与预览，刷新校验值并检查 README 播放；保持无署名版本，不将动画源项目复制到应用源码目录。

这些文件作为项目文档使用，不打进网页 `dist/` 或 Android APK；源码式服务端包会包含文档副本。
