# 使用指南与故障排查

适用版本：**0.4.6**。[返回首页](../README.md) · [配置与扩展](configuration.md) · [部署维护](deployment.md)

## 连接服务器

在登录页服务器按钮或工作台顶部服务器名称处添加服务器，填写名称和完整 HTTPS 地址，例如 `https://workspace.example.com:28443`。地址只包含协议、域名和端口，不带路径、账号密码或查询参数。每台服务器单独登录，服务器列表保存在当前设备。

切换服务器会切换对话、文件和连接，远端正在执行的任务继续运行。移除服务器只清除本机入口和对应凭据，不删除远端工程。登录有效期为七天，过期需要重新登录。浏览器从 A 服务器网页连接 B 服务器时，B 需允许 A 的精确网页来源；见部署文档。

## 对话与项目

1. 选择 Claude Code 或 Codex，新建会话时选择实际项目目录、项目名称和会话标题；可使用既有目录或创建子文件夹。
2. 在对话中发送任务，通过附件入口从手机上传或从服务器文件模块选择文件。每条消息最多 10 个附件；图片上限 20MB，支持 PNG/JPEG/WebP/GIF。其他文件作为经核验的服务器路径提供，读取能力取决于代理。
3. 在模型设置中选择服务器实际报告的模型与思考程度。运行中不能更换，下轮生效；模型列表不保证账号有使用权限。Codex 选择服务器默认时沿用原生配置，显式选择时覆盖默认值。
4. 通过「会话信息 → 重命名 / 管理会话」或会话列表操作修改名称、删除会话。运行中的会话先停止；删除保留项目文件。当前不支持直接修改已有会话的工作目录，需要在目标目录新建会话。

对话页隐藏底部主导航，使用返回操作离开。Markdown 支持表格、列表、引用、任务列表和代码复制；原始 HTML 不执行。思考卡片可折叠，仅显示代理实际返回的可读内容，无法展示供应商未返回的内部过程。需要更多上下文时加载更早消息。

批准卡片展示可获得的命令、目录、原因和变更，必须明确允许或拒绝。问答支持协议提供的选择、补充输入和密码输入，提交后等待确认；无法识别的交互会提示转到终端。点击通知只打开目标，不自动批准。

## 文件模块与预览

「文件 → 管理模块」可以重命名、添加、移除模块，给一个模块绑定多个既有文件夹；例如设置“输出文件”和“输出文件2”。单文件夹直接显示内容，多文件夹先选择目录。移除绑定保留物理文件；有排队或运行任务的绑定不能重映射。

上传、新建文件夹和查看方式位于当前目录的紧凑图标工具栏。单文件最多 512MB；同名上传不覆盖。文本编辑上限 2MB，保存前校验修改时间；冲突时先保留草稿并重新读取文件，不强行覆盖。目录支持移动/重命名、引用到对话和打开终端；进入页面、手动刷新或前台每 10 秒更新列表。

可选范围默认是服务器运行用户 home 与 `STUDIO_BASE`，管理员可修改允许范围。路径解析会检查符号链接和实际边界。

预览链接有效期 15 分钟，失效后重新打开。HTML 在沙箱中运行，不能访问工作台身份；相对资源通过受限链接加载。音视频播放依赖客户端编解码器，PDF 也取决于 WebView；不能播放时下载原文件。高级文件管理入口需要服务器另行配置 FileBrowser。

## 触屏终端

终端的复制、全屏与工具入口保持紧凑；列宽、字号、重连和其他按键放在工具面板，扩展控制键按需展开。适应屏宽优先用于日常输入；80/120 列模式可横向拖动或使用滑块查看右侧。字号、列宽、旋转和全屏调整只改变当前 PTY 尺寸。

中文或复杂命令可先在命令编辑框整理，再明确执行。快捷命令支持名称、多行内容、添加/编辑/删除，按当前设备和服务器保存；点击只填入编辑框，不立即执行。清除应用数据或卸载会移除本机快捷命令。

复制优先采用终端选区，否则取保留的终端缓冲区。自动折行会合并，输出本来具有的换行保留；复制面板允许系统复制和手动选取。终端缓冲区不等于无限完整历史，需要持久日志时使用任务或命令自己的日志文件。

切换底部菜单会保留已打开终端的连接、输出和草稿。实际网络断线后会重新附着服务器 tmux shell；主机重启、shell 自己退出或删除会话不能保证恢复。切换服务器或目录会关闭对应客户端连接。

## 后台任务有什么用

任务模块用于构建、测试、批处理等需要排队、留日志或离开手机后继续执行的命令。交互操作放在终端，需要留存记录的长命令放入任务。

队列一次执行一个任务。可编辑任务名称；命令仅在排队时可改，完成任务可复制为新任务重跑。运行中可取消，取消完成前保持取消中状态；运行中或取消中不能删除。删除记录和日志保留输出文件。网关重启后原运行任务标记中断，尚未执行的队列继续调度，不自动续跑中断命令。

## 额度与 Token

工作台设置中的「额度与 Token」显示所选服务器账号数据；对话标题栏用量图标查看当前会话。账号 Token 和按会话统计默认折叠，展开后可按代理筛选、搜索会话。

| 数据 | 含义 |
| --- | --- |
| 账号额度窗口 | 供应商返回的限制、使用比例和重置时刻，不由 Token 数估算 |
| Codex 会话 | 已报告的线程累计输入/输出；缓存与思考是子项，不再重复相加 |
| Claude 会话 | 当前上下文快照，不能当作累计账单或总花费 |
| 无数据 / 0 | 未报告显示未知；实际报告的零保留为 0 |

Codex 重置时间来自 App Server `account/rateLimits/read` 的 Unix 时间戳，界面按手机/浏览器时区显示时刻、GMT 偏移和剩余时间。服务器在美西、手机在东八区时显示东八区是预期行为；它们代表同一时刻。账号接口缓存 60 秒，手动刷新不会强制刷新供应商。

统计仅反映已报告并留存的数据；旧会话可能没有快照，历史名称也可能缺失。别名会话选择最新快照，不重复累加；不扫描文稿估算 Token，也不估算费用。Claude 额度不可用可能与登录模式、授权或上游接口有关，不代表额度为零。

## Android 系统通知

1. 打开「提醒中心 → 后台提醒设置」，选择服务器与提醒类型，开启后台提醒并允许通知。
2. 使用同频道测试提醒确认系统能显示；检查任务提醒频道、通知权限、最近同步时间和错误状态。
3. 离开 App 后，常驻监听约每 15 秒依次检查已选服务器。提醒可以打开对应会话或任务日志，批准仍需进入对话明确操作。

常驻监听和「任务与批准提醒」是两个独立频道。有常驻通知不意味着任务提醒已开启、有声音或弹出。首次同步不推送更早的完成记录，但会接收开启监听至首次同步之间的新完成事件，以及尚未处理的批准/问答。每台服务器保存独立游标，暂停再开不会重播旧完成记录。

重新打开 App 会恢复此前启用的监听；主动暂停后不会自行恢复。强停、重启、断网、Doze 和厂商省电可能中断或延迟监听。当前使用 Android 前台服务，没有接入 FCM、Telegram 或浏览器后台推送。网页版提供提醒收件箱；服务端最多保留 500 条通用事件，界面展示最近 100 条。标为已读不代表任务或批准已处理。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 常驻通知存在，完成却没提醒 | 发同频道测试通知；检查任务频道是否关闭/静音、最近同步、服务器勾选和登录是否过期；核对事件是否发生在监听开启之后 |
| 点击提醒打不开 | 查看是否登录过期、目标会话/任务已删除或上游暂时不可用；保留收件箱，重新登录或从列表打开，别把失效目标当新会话 |
| 终端右侧看不全 | 使用适应屏宽或固定列宽的横向查看，调整字号；更新到匹配版本后重连 |
| 终端出现 `0;276;0c` | 这是终端设备协商响应被误写入输入的历史问题；0.4.2 网关已处理，更新服务器后重连。已有历史不会自动删除；仍复现时记录客户端/网关版本、时间及网络场景 |
| 配置已保存但模型没变 | 检查会话是否显式选择了模型，是否需要新会话/重启对应代理；保存仅校验语法，不验证连接与账号权限 |
| 配置保存冲突 | 先备份草稿，再重新读取并合并服务器变更 |
| Android 仍是旧界面 | 网页升级不会替换 APK 中的资源；安装同包名同签名的新 APK |
| HTTPS 或跨服务器连接失败 | 检查完整域名/端口、系统可信证书、证书有效期、OCI/主机防火墙和精确 CORS 来源；不要通过跳过 TLS 校验解决 |
